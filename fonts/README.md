# Website fonts

Fonts are self-hosted WOFF2 subsets created locally from Google Fonts distributions. Subsets include current website text, printable ASCII, and kana. New characters outside a subset use the system fallbacks in style.css.

- Shippori Mincho 600: https://github.com/fontdasu/ShipporiMincho
- Noto Serif SC 600: https://github.com/notofonts/noto-cjk
- Zen Kaku Gothic New 400: https://github.com/googlefonts/zen-kakugothic
- Station Mono 500 is a renamed subset of IBM Plex Mono: https://github.com/IBM/plex

Each font's original copyright and SIL Open Font License are retained in the accompanying OFL files. Station Mono uses a new family name to respect the original reserved font name.
