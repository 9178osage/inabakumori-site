# Home-screen icons

Created with the built-in ImageGen tool, using `images/memes/004.png` as the edit reference. Existing artwork rights remain with their respective owners, as described in the project README.

Final prompt:

> Edit the provided existing project character illustration into a square web app home-screen icon. Preserve the same black-and-white chibi character, facial expression, pose and line art faithfully. Center the full character on a solid light gray (#b2b2b2) square background with generous padding so the character fits inside the center 80% safe area. No text, no border, no added elements. Clean recognizable at small size. Output a square PNG.

Exports: `icon-192.png` (192 × 192), `icon-512.png` (512 × 512), and `apple-touch-icon.png` (180 × 180). The manifest declares `purpose: any`; these are not certified maskable icons.
