基线：`6c3cb0b`。审查手写前后端代码、维护脚本、测试及发布配置；生成的认证包通过构建一致性检查，帖子档案和翻译通过现有数据校验。图片、字体不属于源码审查范围。

## 确认并修复

1. **PostgreSQL 回滚失败后复用连接。** 事务异常后的 `ROLLBACK` 自身失败时，原实现仍正常归还连接，可能把状态不明的事务交给下一次操作。初始化、写事务和快照现在均销毁此类连接，同时保留原始错误。合成故障结合 PGlite SQL 验证：失败写入不会被后续正常事务提交。
2. **帖子索引丢失后误清理正文。** `manifest.json` 缺失时原读取函数返回空档案，导入会把仍存留的正文分片清掉。现在检测到正文分片即报错，读取、导入和依赖它们的构建停止；真正的新空目录仍可初始化。回归核对拒绝导入前后的文件列表与正文逐字节一致。
3. **刷新脚本覆盖等待期间的本地编辑。** 播放量和创作者动态工具在网络请求后写回旧快照，可能覆盖期间保存的新编辑。写回前重新检查原文件内容，发生冲突则退出并清理自有临时文件。回归使用隔离目录和合成网络响应；这是写回前冲突检测，不是跨所有编辑器的原子文件锁。
4. **合法最大留言 ID 漏出管理列表。** 首次分页原来使用严格小于最大安全整数的条件，使该合法 ID 永远不可见。现首次包含最大安全整数，显式游标仍排除游标本身，保持参数化查询及安全整数边界。当前线上小 ID 不受此问题影响。
