## 确认并修复的问题

1. **Unicode 强制换行绕过留言行数限制。** 原来只统一 CR/LF，U+2028/U+2029 可避开 15 个换行的限制，昵称也允许内部强制换行。现将正文分隔符统一为 LF，保留原有空行合并和首尾空白处理，昵称拒绝内部行分隔符；前端计数与后端一致。回归覆盖边界 15/16 次换行、混合空行、昵称，以及实际 HTTP 拒绝路径。
2. **存储写入失败后跨标签页显示旧偏好。** quota 失败时的内存值会遮住其他标签页后来成功写入的语言或主题。现只在本页 localStorage 的 storage 事件中清理对应内存值；清空事件清理全部，其他存储区域不影响本页 fallback。
3. **预览白名单可被符号链接绕过。** 允许的脚本、图片文件名或父目录可指向目录外文件，404 回退也有同类问题。现读取前检查真实路径，拒绝链接与非普通文件，保留中性的 404。
4. **公开产物检查未拒绝符号链接及入口特殊文件。** 原检查可能把带链接的构建目录判为通过，FIFO 入口还可能在文件类型检查前阻塞读取；现明确拒绝根目录、入口、文件及子目录中的链接和非普通条目。隔离夹具用私有 canary 和 FIFO 验证不再放行或挂起。
5. **备份 CLI 从路径别名启动会空转成功。** 原入口只比较字面路径，符号链接或 macOS 路径别名可能导致未执行备份却退出 0。现按真实路径识别入口；测试实际检查普通入口与链接入口生成的合成 SQLite 快照、内容及 0600 权限。
6. **播放量刷新可能挂起、泄露外部错误内容或写入失真数字。** 请求及响应体现在共用 15 秒期限，失败输出只含受控错误信息；超出 JavaScript 安全整数范围的计数保留旧值，不把溢出数字写成错误值或 `null`，合法的零播放量仍有效。合成 CLI 测试覆盖请求/响应体挂起、错误中回显密钥、超大计数和零值；未使用真实 YouTube 密钥或伪造公开播放量。
